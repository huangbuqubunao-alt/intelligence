# 产品战略与定位（Product Strategy）

- **生效日期**：2026-11-23
- **状态**：ACTIVE（`PUBLIC_BETA` · Stage 1 价值验证期）

---

## 1. 产品核心定位

> **一句话定位**：面向中英双语研究者与知识创作者的 **本地优先、可核验原文、反幻觉** 多源情报工作台——把 **YouTube 英文原讲 + B 站中文讲解 + 本地 Markdown 笔记**放进同一个受控本地证据库，支持可点检的原话对照问答与诚实拒答，最终带走离开本工具依然可点击回溯原片的 **Obsidian Markdown 研究资产**。

---

## 2. 目标客群（ICP：先窄切、打穿单点，拒绝泛泛而谈）

### 首要楔子客群（Primary Wedge ICP）
- **角色**：深度依赖 **Obsidian / 本地 Markdown 知识库** 的中文技术研究者、AI 产品经理、深度知识区创作者与一线工程师。
- **典型场景**：正在研究一个复杂选题或工程决策，需要同时对照 **YouTube 一手英文长视频（发布/访谈/公开课）**、**B 站中文拆解视频** 和 **自己写下的本地 `.md` 读书/架构笔记**，且极度厌恶大模型胡编时间戳、厌恶云端 SaaS 把资料锁死在专有界面里，同时追求**可审计、可复用、零隐私外泄、成本可控**。

### 次要拓展客群（Secondary，待首轮验证后再考虑）
- 对数据隐私极度敏感（金融、法务、企业研发）且能接受本机 Ollama/BYOK 的桌面科研个人用户。

---

## 3. 核心差异化壁垒（不靠参数量和花哨 UI 跟大厂拼预算）

| 维度 | 大厂免费闭源（NotebookLM） | 国内音视频 SaaS（BibiGPT/通义听悟/ima） | 通用开源 RAG（AnythingLLM/Open Notebook） | **Intelligence 的不可替代切口** |
|---|---|---|---|---|
| **中英双语视频同库（YouTube + B 站）+ Markdown 混问** | 强于 PDF/YT，但原生不支持 B 站 BV 与双向 Obsidian Vault 闭环 | 强于 B 站/YT 总结，但偏向“单次消费”，缺乏跨多源严谨比对 | 以泛文档 RAG/生成播客为主，缺 B 站+YT 短视频降噪与原片时间轴绑定 | **原生统一 YouTube + B 站 + 本地音视频/Markdown 在同一 SQLite 证据链下对比** |
| **反幻觉工程边界（Fail-Closed 拒答）** | Reddit 用户高频抱怨“近期漏用外部通用知识、引用偶发失效” | 大多只做一键生成总结，缺少基于候选边界的硬性拒答契约 | RAG 命中弱时常强行作答 | **没有后端发放的可信 `evidence_id` 直接拒答，仅把候选摘录列在独立仅供参考区** |
| **带原片跳转的可携带导出** | 脱离网页端无法保留可点开原片毫秒位置 | 多在站内看或需 Pro 会员同步 | 导出为纯文本，缺原片秒级深链 `?t=75s` | **导出的 Obsidian `.md` 与纯文本直接携带原片 HTTPS 深链、段落范围 `P#(start–end)` 与 `ev:` 哈希前缀** |
| **隐私与零静默花费** | 全量上传 Google 云端 | 全量上传厂商服务器 + 按分钟阶梯高价会员 | 需自行配 Docker / 复杂环境变量 | **Apache-2.0 单机零遥测、后台严格禁用云端花费、BYOK 日上限与快照重认证保护** |

## 4. 明确的反目标（未来 30 天坚决不做）

为防止陷入功能膨胀与“开源项目常见自嗨症”：
1. **不做**全网爬虫/V2 多平台抓取（X/小红书/全网链接自动抓）——先把已有 YouTube + B 站 + 本地音视频/Markdown 这条核验主链跑透。
2. **不做**自动 `hybrid` 模型自动路由或复杂多智能体炫技——默认本机免费模型 + 用户显式控制的 BYOK。
3. **不做**公网托管 SaaS、多用户账号计费或花哨播客音频生成。
4. **不做**与 Open Notebook / AnythingLLM 正面比拼 Docker 插件数量或 20+ 种模型支持清单。

## 5. 商业模式与盈利路径（全部明确标为：`待验证假设`）

当前产品开源免费阶段（Apache-2.0）：**不收任何授权费，绝不以“圈人套壳”方式收费。**

待后续达到留存门槛（10 名以上活跃研究者、第 2 周留存 `>=40%`）后，验证以下 **三个可成立的商业切口（待验证假设）**：
- **路径 A（开源 Core + 商业工作流增值包，最契合个人与小团队）**：Apache-2.0 核心永久免费可用；对高频创作者/投研分析师提供可选付费「Pro 自动化研究包」（例如：定时专题追更 + 自动 Obsidian 双向 Vault 增量写入、双语术语对照与批量选题审校模板，一次性买断 \$29–\$49 或低门槛年费）。`[待验证假设]`
- **路径 B（企业/投研/研发团队私有化知识核查部署）**：为 5–20 人研究团队提供内部共用可审计证据库 + 统一事实核查报告导出与权限模板，按团队席位或部署支持服务收费。`[待验证假设]`
- **路径 C（绝不采用的低概率路径）**：按视频转写/总结分钟数倒卖大模型 Token——与 BibiGPT、通义听悟等大厂补贴/API 中间商正面拼毛利毫无优势，坚决放弃。

---

## 6. 退出或转向条件

若未来 30 天内连续两批（累计 >=15 位目标研究者）试用后，出现以下任一信号，立刻触发 L3 战略复盘或止损转向：
- **冷启动过重无法激活**：>60% 目标用户卡在安装 Ollama / Python 环境 / yt-dlp 中途放弃（则优先评估单文件桌面壳或零配置本地引导，而不是加新功能）。
- **核心差异点无人买单**：用户普遍认为“Google NotebookLM + BibiGPT 免费额度已足够，不关心原片回溯与 Obsidian 双链导出”（则停止围绕 Obsidian 科研定位做重投入，重新调研更高频痛点）。

## EXP-001：首批 10 位双语研究者真实试用激活与核心价值闭环验证（`FD-002` 方案 A 已批 · 待对外触达）

- **实验状态**：**APPROVED FOR OUTREACH (`FD-002` 方案 A · 2026-11-23)**（前置：主线 CI 绿灯与仓库转 Public 后提供邀请文案由创始人私域定向发放）
- **核心假设**：目标 ICP（习惯使用 Obsidian 且同时看 YouTube 与 B 站的长视频学习者）能在 <=15 分钟内完成「冷启动 → 导入 >=2 份跨源资料（1 视频 + 1 `.md`/另平台视频） → 验证 1 次有引用作答与 1 次无依据拒答 → 导出含原片深链 Markdown 进个人知识库」，且至少 30% 在第 7 天再次自发使用。
- **目标受众 & 渠道**：通过 founder 个人私域、Obsidian 中文社区小圈子或 V2EX 征集 **5–10 名** macOS/Linux/WSL 受邀内测者（严禁群发骚扰营销）。
- **核心信息（不夸大）**：`“把 B 站中文解析、YouTube 英文原讲和你的本地 Markdown 放在一台电脑里互相对照，有证据就给原话带跳转链接，没证据直接拒答，笔记原样导进 Obsidian。”`
- **预算与资源消耗**：**$0**（全自然/私域小范围邀请；用户跑免费本机 Ollama 或用自己自带 Key）。
- **观测指标**：
  1. **冷启动安装完成率**（成功打开工作台且加载本地或模型配置的比例）；
  2. **15 分钟研究闭环达成率**（真正做出 1 份带导出笔记的比例）；
  3. **第 7 天回访率（W1 Retention）** 与最大阻塞卡点记录。
- **停止/止损条件**：前 5 位试跑者若超过 3 位在“装环境/跑模型”阶段卡死无法进入界面，立刻暂停招募，转全力优先攻克零配置安装包问题。
- **复盘结论**：**暂无数据（未执行）**。

## EXP-002：真实本机 Ollama 模型处理陌生双语资料反幻觉实战基准（已完成 `PASSED`）

- **实验状态**：**PASSED（2026-11-23 隔离实测完成）**
- **核心假设**：本机开源模型（默认 `qwen3.5:9b`）在无人工修稿情况下，处理陌生跨语言双语材料时，**有依据问答命中原话率 >= 80%** 且 **诱导性无依据问题拒答率 >= 80%**（即使模型遗漏引用也会被后端 Fail-Closed 兜底拦截）。
- **预算与资源消耗**：**$0**（完全运行在本机离线 Ollama 回环端口 `127.0.0.1:11434`，模型 `ollama/qwen3.5:9b`，绝不触发任何付费云端 API）。
- **语料来源如实披露**：`yt-dlp` 免 Cookie 抓取公开 YouTube 样本触发机器人校验提示（按安全红线拒绝绕过或使用个人 Cookie），故本基准采用 `unseen_controlled_bilingual_benchmark_corpus`（虚构频道 `Kestrel Systems Lab` YouTube 英文长片段 + 虚构频道 `北极星架构实验室` B 站中文对照字幕 + 本地 Markdown `memory-benchmark-field-notes.md`）。
- **实测结果与指标**：
  - **可答跨源问答**：**3 / 3（100%）`GROUNDED`** — `Q1` 共识判断 `56.27s`（3 条引用，含 `?t=90` / `&t=42s` / `?t=64`）；`Q2` 条件分歧 `54.22s`（3 条引用，精确区分 8GB 选 9B 与 32GB 多文档选 32B）；`Q3` 视频+Markdown 跨源 `44.22s`（4 条引用，同时命中本地文档 `TEXT_RANGE: P2 (47–213)` + B 站 `?t=115` / `?t=64` + YouTube `&t=85s`）。
  - **诱导性无依据拒答**：**2 / 2（100%）`REFUSED_INSUFFICIENT_EVIDENCE`**（`refused: true`、`citations: 0`、独立保留 `related_excerpts: 3`）— `Q4`（虚构 2027 ARR/融资估值）`30.84s`；`Q5`（虚构 TPU v6p / GPT-6.5 / v9.4 准确率）`42.05s`。
  - **端到端耗时与导出验收**：5 问总耗时 `227.6s`（平均 `45.5s`/问）；`obsidian_markdown` 导出包含 `核验覆盖材料（3 份）`、`https://...?t=` 外链、`ev:` 指纹，且本地 Markdown 引用无 `00:00` 伪时间戳。
- **复盘结论**：默认本机 `qwen3.5:9b` 与后端 Fail-Closed 门禁配合稳定，满足对外 Public Beta 实测置信条件。

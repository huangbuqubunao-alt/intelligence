Severity rules:

- **P0:** unsafe/trust-breaking, or broadly relevant core journey impossible;
  one credible safety event may qualify.
- **P1:** repeated major task failure or severe misunderstanding.
- **P2:** meaningful repeated friction while users can continue safely.
- **P3:** isolated polish or preference.

Do not promote an issue solely because one participant strongly dislikes it.

## 4. 产品亮点（用户体验角度）

1. **证据始终可追溯**不是口号：字幕→时间戳→哈希→原始链接全链路真实可查。
2. **诚实反馈**贯穿产品：模型不可用、字幕不可用、备份被占用都如实说明，从不编造。
3. **本地优先**落实：文件在本地快照、凭据不显示、云端处理需逐次授权。
4. **空状态与提示友好**：每个空页面都有可执行的下一步。
5. **状态机清晰**：内容处理各阶段状态在 UI 与处理记录中一致呈现。

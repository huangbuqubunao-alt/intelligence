## 1. Intelligence 是什么

**Intelligence 是一个"本地优先"的个人智能知识工作台**。它帮助你：

- **持续关注**你感兴趣的信息来源（如 YouTube 频道）；
- **采集内容**（视频、字幕、本地文件），自动**转写、摘要**并保留**证据**；
- 从内容中**提炼长期有价值的洞察**；
- 围绕主题**持续积累和演化认知**。

它的四个核心概念：

| 概念 | 作用 | 通俗解释 |
|------|------|----------|
| **Following（关注）** | 持续关注的信息来源 | 就像订阅一个频道 |
| **Content（内容）** | 采集、转写、摘要和证据 | 整理好的素材库 |
| **Intelligence（洞察）** | 从内容中提炼的长期价值 | 值得记住的结论 |
| **Topic（主题）** | 围绕主题积累认知 | 按主题归档洞察 |

**产品原则**：
- Following → Content 是**基础能力**：默认帮你整理内容。
- Content → Intelligence 是**可选能力**：你可以选择进一步提炼洞察。
- **默认本地处理**：你的数据保存在本机，不会未经授权调用付费云端模型。

**最重要的承诺：证据始终可追溯。** 每一条内容、每一个摘要、每一条洞察，都能找到它来自哪段原始材料。

## 2. 第一次使用

第一次打开 Intelligence，你会看到三步引导，说明这个工具的核心用途。

**第 1 步：欢迎与定位**——页面说明这是一款"本地优先的知识工作台"，点击 **继续** 进入下一步。

**第 2 步：理解"关注 → 内容 → 洞察"**——介绍持续关注来源、快速理解内容、积累知识。

**第 3 步：了解"证据始终可追溯"**——说明内容可在不调用云端洞察的情况下整理，部分视频可能没有可用字幕。

**完成引导**：点击 **添加内容** 完成引导，进入"关注"页面。（截图待 GUI 环境补拍）

此时页面还是空的，提示你"选择要持续关注的来源"。左侧是导航栏：

| 导航 | 功能 |
|------|------|
| 首页 | 最近 7 天你关注的知识发生了什么变化 |
| 关注 | 管理你持续关注的来源 |
| 内容 | 阅读已采集的内容、字幕与处理记录 |
| 洞察 | 查看提炼出的长期洞察 |
| 主题 | 按主题归档和浏览洞察 |
| 设置 | 语言、兴趣、模型、备份等 |

**重新打开后的状态**：关闭浏览器再打开，你的关注、内容、设置都会保留（数据保存在本机）。

> 说明：你首次使用时会看到空状态页面；本手册中"演示环境已有数据"的说法均指此前测试环境，不代表你首次打开的样子。

## 3. 添加 YouTube 视频

可以**单次导入**一条 YouTube 视频，不关注频道。

**操作步骤**：

1. 点击 **添加关注**，打开添加对话框。对话框提示："粘贴 YouTube 或 Bilibili 视频链接，持续关注 YouTube 频道，或导入本地文件。"
2. 在输入框中粘贴 **YouTube 视频链接**，例如：`https://www.youtube.com/watch?v=aircAruvnKk`
3. 系统会识别链接并显示视频信息（标题、频道）。
4. 点击 **添加** 确认导入。导入成功后，内容会自动进入后台处理（获取字幕、生成摘要）。

**预期结果**：
- 视频出现在 **内容** 列表中；
- 处理完成后显示"已完成"；
- 打开详情页可以看到字幕、摘要和证据。

## 4. 关注 YouTube 频道

持续关注一个频道，之后自动检查该频道的新视频。

**操作步骤**：

1. 打开 **添加关注** 对话框，粘贴 **YouTube 频道主页链接**，例如：`https://www.youtube.com/@Veritasium`
2. 系统识别出频道名称。
3. 点击 **添加**，频道出现在"关注"列表，状态为"正在关注新视频"。

**关注后的操作**：

- **暂停关注**：点击频道卡片上的 **暂停关注**，频道状态变为"关注已暂停"，已有内容仍然保留。
- **恢复关注**：点击 **持续关注**，频道恢复"正在关注新视频"。

**自动检查**：应用运行时会自动检查已关注的频道是否有新视频（两次检查至少间隔 15 分钟）。**当前版本没有手动"检查更新"按钮**，检查完全自动进行。

> 提示：如果某个公开来源暂时不可访问，页面会如实提示"此公开来源不可用，已保留存储的内容"，不会删除你已有的内容。

## 6. 导入本地文件

可以导入本机的文本、音频或视频文件。

**支持的格式**：
- 文本：`.txt`、`.md`（Markdown）
- 音频：`.mp3`、`.m4a`、`.wav` 等
- 视频：`.mp4`、`.mov`、`.m4v` 等

**操作步骤**：

1. 在 **关注** 页面找到 **本地资料库**，点击 **导入文件**。
2. 选择你的文件：
   - **在 macOS 上**：应用会打开系统的原生文件选择窗口（由本机后端弹出，非网页弹窗）。
   - **在其他系统 / 非 Mac 浏览器上**：使用浏览器内置的文件选择框选择文件。**macOS 原生选择器在非 Mac 环境不可用**，这是平台限制，不是故障。

对话框中说明了文件格式与大小限制：**TXT/MD 最大 2 MiB，音频/视频最大 2 GiB，媒体时长最长两小时**，且"所有内容都保留在本机"。选择不支持的文件时，系统会显示明确的错误提示并拒绝导入。

**导入后的状态**：

- **文本文件**（TXT/MD）：直接整理为内容，可阅读原文。
- **音频/视频文件**：显示"待转写"，应用会尝试使用本地转写能力生成字幕。打开该内容的详情页可以看到转写进度；转写能力不可用时会如实显示"正在检查本地转写能力…"及原因。

> 注意：本地转写依赖一个约 1.6 GB 的语音识别模型。如果模型尚未配置，音频/视频会保持"待转写"状态，页面会如实说明原因，不会假装已经转写成功。

## 7. 查看 Content（内容）

所有采集到的内容都汇总在 **内容** 页面。

**列表**：每条内容显示标题、来源（频道/本地文件）、时间和处理状态。

**处理状态说明**：

| 状态 | 含义 |
|------|------|
| 已完成 | 字幕与摘要已整理完成 |
| 待转写 | 音频/视频正在等待转写（或转写能力不可用） |
| 字幕不可用 | 源没有可用字幕，如实提示 |
| 处理中 | 正在获取字幕或生成摘要 |

**打开详情**：点击任意内容条目，进入详情页。详情页包含：视频信息（标题、频道、发布时间）、**打开原始来源** 链接、**关注此频道** 快捷入口、**原始字幕**、**来源位置/溯源信息**（证据）等。

## 8. 查看字幕与摘要

在内容详情页可以查看**原始字幕**与**摘要**。

**原始字幕**：逐段显示带时间戳的字幕文本，对应视频的具体时间段。

**来源位置与溯源信息**：每段字幕都标明它在视频中的时间位置，并显示对应的证据文件哈希与日期——这就是"证据始终可追溯"的体现。点击 **打开原始来源对应时间点** 可直接跳转到原视频对应的时间。

**摘要**：系统基于字幕整理的结构化摘要（关键点）。如果内容没有字幕或尚未整理完成，摘要区域会如实显示"不可用"，并说明不会根据缺失的结果编造摘要。

**处理记录**：详情页底部显示该内容的处理历史（例如"原始字幕：已完成""来源信息：已完成"）。

## 9. 理解 Evidence（证据）

**Evidence（证据）是 Intelligence 的核心信任机制**：任何结论都能追溯到原始材料。

在内容详情页，你会看到：

- **来源位置**：证据在原始视频中的时间段；
- **溯源信息**：证据文件的哈希值与日期；
- **打开原始来源对应时间点**：点击可直接跳转到原视频对应的时间。

证据的意义：
- **不编造**：系统不会根据缺失的内容编造摘要或洞察；
- **可核验**：每条洞察都引用原始证据，你可以回看原文验证；
- **可追溯**：从洞察 → 证据 → 原始材料，链路完整。

## 10. 提炼 Intelligence（洞察）

在内容详情页的"洞察处理结果"区域，可以手动触发提炼：点击 **提炼为洞察**。

**处理过程**：系统使用你配置的本地模型分析内容与证据，判断是否有值得长期保留的新洞察。

**两种结果**：

1. **发现新洞察**：生成洞察条目，可在 **洞察** 页面查看，并关联到主题。
2. **无新洞察**：如实显示"已完成，未产生新洞察"——说明分析已完成，但本次内容没有形成值得长期保留的新结论。

**洞察页面**：所有提炼出的洞察汇总在这里；如果内容正在分析，会显示处理进度。

> 提示：提炼洞察是**可选**操作。不提炼也不影响内容整理。未配置合格模型时，页面会明确提示"云端洞察需要配置凭据并授权"，不会偷偷使用付费服务。

## 12. 配置本地模型

Intelligence 默认使用**本地模型**完成内容整理与洞察提炼，你的数据不出本机。

**查看当前模型**：打开 **设置 → 模型与处理准备**。

**当前使用的本地模型**区域显示：
- 模型名称（例如 `qwen3:8b`）；
- 状态（"已安装，可使用" 或 "准备情况需要处理"）。

**配置要求（不做过度承诺）**：
- 本地模型通过本机 Ollama 服务提供；
- 应用在**每次使用前都会核对模型的精确标识（digest）**：只有与配置中记录的 digest 完全一致的已安装模型才会被使用，这是防止用错模型处理你数据的安全机制；不匹配时相关功能会如实提示不可用，不会静默降级、用别的模型代替；
- 模型未就绪时，内容整理与洞察提炼会如实提示不可用。

**在设置页的"模型与处理准备"中展开"云端配置与模型详情"**，可以看到模型连接状态与可用模型列表（只读）。

> 提示：安装本地模型需要一定的技术准备（安装 Ollama 并拉取指定模型）。对于不想配置模型的用户，核心的内容整理功能依然可用；只有"提炼洞察"等模型功能会提示不可用。

## 13. 配置云端模型

云端模型是**可选**能力，用于更高质量的洞察提炼。

**在设置页的"洞察"区域**，当前状态会明确说明：

- 未配置凭据时：**"云端洞察需要配置凭据并授权。内容整理仍可使用。"**

**使用规则**：
- 云端处理**需要你单独配置凭据，并为每一次请求明确授权**（产品原则：不得未经授权自动调用付费云模型）；
- 凭据值**永远不会**在界面中显示；
- 即使不配置云端模型，内容整理、字幕、摘要等基础能力完全不受影响。

## 14. 修改语言

可以修改**界面语言**与**生成内容的语言**（中文或英文）。

**操作步骤**：

1. 打开 **设置** 页面，找到 **语言** 区域。
2. 点击 **编辑语言**。
3. 选择 **界面语言** 与 **默认输出语言**（默认输出语言影响以后生成的摘要/洞察的语言）。
4. 点击 **保存语言**。

**说明**：
- 来源语言自动识别；
- 语言选择只影响**以后**生成的内容，已有内容保持不变；
- 界面语言保存在当前浏览器配置中，重启应用后仍有效；界面语言偏好不包含在核心数据备份中。

## 15. 备份与恢复

**备份内容**：备份包含洞察核心数据与已保存设置；**不包含**外部资料库、凭据和模型文件。

**创建备份**：

1. 打开 **设置 → 备份与恢复**。
2. 点击 **创建备份**，系统生成一个备份文件（`.zip`），列出备份中的内容统计（关注数、内容数、证据数等）。

**备份前检查**：如果有内容正在处理（例如提炼任务仍在执行），页面会提示"以下工作尚未结束，暂时无法备份"，等处理完成后即可备份。这是为了保证备份数据的一致性。

**选择备份（恢复）**：点击 **选择备份** 可从备份文件恢复数据。恢复完成后需要重新打开应用。

## 16. 常见问题

**Q1：我的数据存在哪里？**
A：默认保存在你本机的数据目录中（本地优先）。凭据值永远不会被显示。

**Q2：添加的视频一直没有字幕/摘要？**
A：检查内容详情页的状态提示。如果显示"字幕不可用"或"待转写"，说明源没有可用字幕，或本地转写模型尚未配置。系统不会编造内容，这是如实反馈。

**Q3：点击"提炼为洞察"后一直显示处理中？**
A：提炼需要本地模型参与。如果模型未就绪，会显示等待状态；请检查设置中的"当前使用的本地模型"是否"已安装，可使用"。云端洞察则需要先配置凭据并逐次授权。

**Q4：浏览器后退/前进按钮没有反应？**
A：旧版本存在此问题，本手册对应版本已修复：点击浏览器后退/前进按钮，或直接在地址栏修改 # 后的路径，都会正确切换页面。

**Q5：为什么不能持续关注 Bilibili UP 主？**
A：当前版本暂不支持 Bilibili UP 主持续关注，但可以单次导入公开 Bilibili 视频。这是当前已知限制。

**Q6：如何修改语言？**
A：设置 → 语言 → 编辑语言，选择界面语言与默认输出语言并保存。

**Q7：备份时提示"暂时无法备份"？**
A：说明有内容正在处理（如提炼任务执行中）。等处理完成后再创建备份即可。

**Q8：可以删除内容或取消关注吗？**
A：当前版本的内容与关注在界面中**没有提供删除入口**（源码已核对：无删除内容/取消关注的按钮与接口）。如需清理数据，请等待后续版本或联系维护者。本手册对应版本以添加、关注、整理、提炼为主。

**Q9：在非 Mac 电脑上导入本地文件时没有弹出系统文件窗口？**
A：正常。macOS 原生文件选择器仅在 macOS 上可用；在其他系统上，应用使用浏览器内置的文件选择框，功能一致（选择文件 → 本地快照导入），只是外观不同。

## 17. 当前已知限制

以下是本手册撰写时（2026-10-11）经源码核对确认的限制，均如实记录：

| 限制 | 表现 | 说明 |
|------|------|------|
| **本地音频/视频转写依赖模型** | 导入的音频/视频显示"待转写" | 需要约 1.6 GB 的本地语音识别模型。模型未配置时，转写能力检查会如实报告"暂不可用" |
| **Bilibili 字幕可能不可用** | 导入的 Bilibili 视频显示"字幕不可用" | 部分 Bilibili 视频无公开网页字幕，或受源站访问限制；后端能力表明确标记该能力不可用 |
| **Bilibili UP 主持续关注不可用** | 添加对话框仅提供 YouTube 频道持续关注 | 代码层明确关闭（`CREATOR_FOLLOWING_AVAILABLE = False`）；Bilibili 仅支持单次公开视频导入 |
| **macOS 原生文件选择器为 macOS 特有** | 非 Mac 环境使用浏览器文件选择框 | 后端原生选择器仅在 macOS 生效；功能一致，仅选择方式不同 |
| **云端洞察需要凭据与逐次授权** | 设置页明确提示"需要配置凭据并授权" | 产品原则：不自动调用付费云模型 |
| **2 GiB 大文件导入未实测** | — | 导入存在明确的文件大小上限（文本 2 MiB / 媒体 2 GiB / 时长两小时）；2 GiB 边界未实际验证 |
| **主题需先有洞察** | 主题页面为空 | 主题归档的是已提炼的洞察；产生第一条洞察前主题为空是正常现象 |
| **内容/关注暂无删除入口** | 界面无删除按钮 | 当前版本以添加、关注、整理、提炼为主 |
| **转写与提炼需要模型就绪** | 状态提示"等待模型/转写能力检查中" | 模型未就绪时系统如实提示，不会静默降级；本地模型每次使用前核对 digest，不匹配则不可用 |

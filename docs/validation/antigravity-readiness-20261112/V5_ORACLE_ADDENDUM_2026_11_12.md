## 1. 三类结果的定义（评审口径）

1. **摘要补充**：完整 Summary 没有包含的原文内容，被如实转述、翻译或归纳。它不是 Intelligence。如果输出只靠摘要补充撑起正向结果，判 FAIL（同原 oracle“翻譯原句…不足”）。
2. **新增判断（正向 Intelligence）**：针对 TASK 兴趣、从已引用 Evidence 推出、完整 Summary 没有陈述过的结论、解读、含义或决策考量。必须作为系统分析表达，写明依据、条件或范围，以及什么情况会确认或修订它。不要求固定措辞、固定方向，也不要求一定包含实验建议；“实验/验证方案”只是可接受的一种形式，不是加分项，更不是必需项。
3. **诚实 NO_NEW**：找不到符合第 2 条的候选判断时返回。来源不涉及兴趣、只有摘要补充、只剩通用提醒，都属于这种情况。按原 oracle，它是合法结果。

## 2. 正向结果怎样判 PASS

- 至少有一条判断（通常在 `core_conclusion`）满足 1.2，并且全文没有事实、归属、Evidence 或注入方面的 P0/P1 问题，判 PASS。
- 支持字段里偶尔出现与 Summary 重叠的背景句，如果只是为了让判断可读，记为 P3 观察，**不单独构成 FAIL**；如果正向结果除了复述和补充就没有满足 1.2 的判断，判 FAIL（与 r2 拒绝口径一致）。
- 评审必须写明满足 1.2 的具体句子位置，以及它为何不同于 Summary 和原文的复述；不能只写“有新意”。

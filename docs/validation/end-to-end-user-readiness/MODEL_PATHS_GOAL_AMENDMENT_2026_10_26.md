# 当前 Goal 补充：以普通用户可用的模型路径为目标（2026-10-26）

Authority: 用户在当前主会话明确追加要求；沿用现有 Goal 与持续授权，保留全部已验收成果，不另起开发阶段。此补充优先于“必须先找到合格本地 Intelligence 模型”的旧执行解释；Goal 工具当前usageLimited且仅支持状态更新，不新建或伪称重置 Goal。旧objective中的“不付费上云”在本补充下解释为：没有具体数据/费用授权绝不产生新费用，不禁止评估和配置可选付费路径。

## 产品目标和三条路径

普通用户通过合适模型完成核心操作；不要求本地模型先全部合格。同步评估：本地（硬件与真实质量均合格才推荐）、免费云端（核实当前免费额度、网络、隐私及用途限制，不保证永久/无限免费）、付费云端（质量优先、配置可选、费用预算授权清楚）。不穷举服务，优先复用现有实现和真实验收，尽快证明一条正常用户可操作的完整路径。转写、摘要、洞察的配置/可用性/资格分别报告，任何单项通过不代表全部通过。

## 最小实施范围

现有框架、Evidence、可信读写、预算/费用、授权、模型执行和持久化、Backup/Restore安全边界保持。优先配置与有限adapter扩展，禁止大规模重开发。已验收本地导入、Native Picker/APFS、Whisper、字幕恢复、取消/备份、6003/1026回归等成果保留。Gemma E4B当前profile真实首例已独立REJECT：3P1语义+1P2引用叙述，协议/资源/清理通过；once保留，不重试/不授资格。Granite4.1的只读官方元数据调研暂列DEFER，尚未下载权重/实施adapter，不作为云路径前置条件。

首次使用给简洁模型配置引导；跳过后在相关操作需要模型时直接进入设置，并保留Content/草稿/进度。模型不可用、资源不足、断网、额度/预算耗尽、429限流时显示具体原因和可行的切换/重试/等待/取消入口。不得静默上传、自动转付费、复制重放已执行/未知请求或永久阻塞Backup。切换不能伪造完成或删除历史；旧输入/失败/账本/未知状态保留。任何重试需遵守现有at-most-once和未知执行failclosed。

## 验收和授权

先核对最新代码、权威规范和最新真实验收，再决定最小差距。现有云端provider authority的名字或旧文档首段不等于当前可用：核对最新Owner stop/addendum、真实receipt、能力scope、endpoint/model/prompt版本、授权、可达性及预算。优先检查已通过M12的Moonshot K2.6，与已停止的NVIDIA K3历史区别；不复用旧execution/consent/budget identity。

三路径分别记录：真实通过 / 仅模拟通过 / 未验证 / 不可用；账户额度与实际成本未知就如实标UNKNOWN，不把HTTP可达或配置了key当质量通过。首条路径必须走真实普通用户Content→所需转写/摘要/Evidence→经明确选择和授权的模型洞察→保存/主题/证据回跳→重启→完整Backup/Restore，并逐项核对数据。其他路径的设置步骤、已验证能力、限制与剩余阻塞写清楚。没有方案则实报，禁止降低质量标准制造成功。

必要代码/相关文件/有限provider适配、安全持久化及有兼容恢复方案的迁移按用户持续默认授权在隔离环境推进并记录，不逐文件询问。新增付费、发送私人数据、无关凭据、外部注册/承诺、破坏性动作仍需具体确认；不从调研推定付费或私有上传许可。可先用公开/合成无私人数据准备验证；免费API是否真正零收费须先核实。任何实际请求前保留产品逐次云端同意、精确输入scope、预算及一次dispatch保护。没有授权时继续独立工程和离线验收，不停工等待泛泛审批。

既有main采用授权仍只在全部相关验收、无P0/P1、数据保护与拓扑安全后执行ff-only/push/build/served revision；未达条件保持候选，禁止force/重置owner。最终报告按普通用户路径区分可用性，不以local-only合格作为采用前提，也不虚报本地资格。完成后停止。

## 二、最终人群决策

1. **唯一核心目标人群（Primary Persona）**：**「持续追踪前沿动态的 AI 行业研究者 / 深度技术架构师」**（代表名：**Lin，29 岁，资深 AI 工程研究员 / 技术架构负责人，用 Mac Apple Silicon + Obsidian**）。
2. **两个次级目标人群（Secondary Personas）**：
   - **独立开发者与一人公司创业者**（强调“零订阅剥削、本机 Ollama + BYOK、直接提取产品切口与可执行动作”）；
   - **重度研究型产品经理与行业分析师**（强调“多源观点对比、可审计证据链、直接粘贴进决策简报的可信输出”）。
3. **当前明确不服务的人群（Explicit Non-Targets）**：
   - **只总结单条视频的轻度观影用户**（已经被 YouTube 原生摘要免费教育，留存极低）；
   - **移动端通勤播客听众**（无法在无原生手机 App 的情况下正面竞争 Snipd）；
   - **重度学术 PDF/空间白板写作者**（不与 Heptabase/Zotero 竞争画布与文献管理器）；
   - **多人实时云协作团队**（不偏离当前高安全本地单机底座）。

## 三、核心目标用户画像与任务地图（Lin 的真实一天与一周）

### 人物画像：Lin（AI 行业研究者 / 架构负责人）
- **工具栈**：MacBook Pro M-series (16GB)、Obsidian（个人主力知识库，已沉淀 800+ 篇笔记）、本地 Ollama（已有 `qwen3.5:9b`）+ 按需 OpenAI/Kimi API Key、YouTube（关注 25 个 AI 实验室/一线工程频道）、Bilibili（关注 10 个硬核公开课/架构复盘 UP 主）、本地存放的项目 `.md` 复盘文档。
- **核心焦虑与痛点**：
  1. **信噪比崩塌**：关注频道一周发 40 个视频，其中 60% 是 2 分钟演示短片、标题党直播切片或老调重弹，真正值得深读的核心技术探讨只有 4–5 篇。
  2. **信任破产与溯源耗时**：用常规 AI 总结工具总结 1 小时的技术分享，经常漏掉前提条件（如“仅限单机低并发适用”）甚至把参数数字总结错；为了核实一句话，得在视频进度条里拖动半天。
  3. **知识跨源孤岛**：一周前 A 频道讲状态机优于自由循环，今天 B 站公开课又讲了另一套校验思路，自己本地也写了设计备忘——如果不能把它们放进同一个地方做“跨来源共识与分歧对照”，看过等于没看过。
  4. **资产流失恐惧**：看到心头好视频准备过两周再看，结果原视频被设为私密；或者某款 SaaS 倒闭/涨价，笔记全锁死。

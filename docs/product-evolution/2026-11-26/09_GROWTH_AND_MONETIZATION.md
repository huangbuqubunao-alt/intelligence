## 一、产品定位与价值主张（Positioning & Messaging）

### 1.1 一句话外部传播定位
- **中文主标语**：**「长视频与研究资料的可核验本地工作台」—— 先滤掉频道噪音，再生成句句可跳回原片秒数的双语洞察，一键沉淀进你的 Obsidian 知识库。**
- **英文主标语（Show HN / GitHub）**：**Local-first video & document research workbench: filter channel noise, verify every claim against exact source timestamps, and own every note in Obsidian.**

### 1.2 核心人群必打三痛点（对照竞品缺口）
1. **反信噪比崩塌**：订阅 20+ 技术频道后 60% 是 Shorts 与注水更新 → 本机自动折叠 Shorts、算出频道干货率（Iter 5），首页每日给出高优待读排期（Iter 2）。
2. **反 AI 瞎编（Anti-Faithful-Slop）**：严肃研究不能容忍伪造数字或找不到出处 → 底层三态核验（原文直接支撑 / 启发式推断 / 证据不足诚实拒答），一点直达原片秒数或 `.md` 原文段落，并用人话解读可信依据（Iter 1 / Iter 3）。
3. **反云端锁死与多份月费**：Mem.ai 停服（`M-02`）与 NotebookLM 删源/动态 5h 算力限流（`M-01`）、BibiGPT 按分钟计费焦虑（`M-05`） → 本地 SQLite 抗删源 + 免费 Ollama 跑日常初筛 + 可选 BYOK 钥匙串隔离 + 一键复制/导出 Obsidian `.md` / `.zip`。

## 二、冷启动获客与 0 → 100 → 1,000 GTM 路径

鉴于团队规模极小且无投放预算，**坚决不做泛流量买量广告**，聚焦高信任、高技术密度的“社区口碑 + 开源分发 + 真实对照演示”路线：

### 2.1 阶段 1（0 → 100 种子核心用户）：公开透明的工程信任秀
- **GitHub Open-Core + Demo Showcase 零门槛体验**：
  - 提供独立离线 Demo（`youtube-intel demo`）：用户不配 API Key、不翻墙即可 30 秒体验 YouTube + B站 + 本地 `.md` 跨源问答、`[E1]` 原片定位与 Obsidian 导出。
- **精准中文技术/PKM 社区首发（V2EX / 即刻 Obsidian 圈 / 少数派）**：
  - **核心故事线**：不讲“又一个 AI 总结器”，讲《*为什么我放弃月费摘要工具：用本机 Ollama + SQLite + 三态核验保护我的 Obsidian 研究库（顺带解决频道 Shorts 噪音与 B 站/YouTube 混读）*》。
  - **视觉锚点**：直接附上「Research 跨平台精准引用 + 拒答红线」和「专题跨来源观点对照」的实机对比截图（Iter 1 / Iter 4）。
- **英语全球开发者首发（Show HN / `r/ObsidianMD` / `r/LocalLLaMA`）**：
  - 精准踩中 `r/ObsidianMD` 反 Mem 锁定焦虑、以及 `r/notebooklm` 对 30 天 Source Rot 与无 Obsidian 导出的真实抱怨（`M-01`, `M-02`）。

### 2.2 阶段 2（100 → 1,000 活跃核心用户）：内容复利与工作流模板裂变
- **Obsidian Vault 模板包传播（Built-in Referral）**：
  - 当用户把专题 MOC 导出发到博客/即刻/知识星球时，笔记内自带可读的结构化时间轴引用锚点与来源说明，成为自然品牌名片。
- **高频对比评测短视频（B 站 / YouTube，仅规划不代发）**：
  - 用同一段 1 小时多方技术访谈分别实测 NotebookLM vs 泛摘要插件 vs Intelligence，重点对比「原视频转私密后笔记是否还在」「跨两周对比 3 个博主结论是否乱编数字」。

## 四、商业化模式、定价设计及付费墙边界（`EVO-09`）

### 4.1 为什么不按月对 API Token 加价抽水？
从 `02_MARKET_RESEARCH.md`（`M-05`, `M-07`, `M-08`, `M-09`）可见：
- Eightify / Glasp / Fabric / Heptabase 的用户正强烈抗拒 **“Credits 焦虑 + 为通用大模型再付一次中间商溢价”**；
- BoltAI（\$79–\$399 一次授权）和 TypingMind（\$39–\$99+ 买断）已经充分验证：**技术向用户极度接受“免费开源/基础能力自带 + 为省心高效的桌面封装、工作流自动化和跨库整合买单”**。

### 4.2 建议商业分层架构（本地核心永不锁死，按工程/自动化深度分层）

| 版本档位 | 定位与核心权益 | 建议定价 `[假设 / 待验证]` | 为什么这个切分合理（不伤核心信任） |
|---|---|---|---|
| **Open Core（本地免费版）** | 本地 CLI + Web 工作台；YouTube/B站/本地文档导入；本地 Ollama（零外部费用）或自带 BYOK；完整三态证据链核验；单篇与专题 `.md` / `.zip` 自由导出；无功能到期锁死 | **\$0（永久可用，MIT / Open-Core）** | 建立“绝不锁死用户数据”的绝对口碑护城河，吸引 `SurfSense`/`Obsidian` 社区裂变传播 |
| **Solo Researcher Pro（个人买断 / 年升级授权）** | 原生打包签名 macOS/Windows 桌面一键安装包（免配置 Python/uv/ffmpeg 环境）；后台定时频道信噪比巡检与推送；Obsidian Vault 增量自动化直写与双向同步插件（待 L3 授权后启用）；跨视频研究高级比较模板与批量导出 | **早鸟买断 \$59（或年续更新 \$39/年）** `[假设 / 待验证]` | 锚定 TypingMind (\$39–\$99+) 与 BoltAI (\$79) 的买断心智，一次性省回 3 个月 BibiGPT Plus（~\$59.4）的支出 |
| **Future Team / Research Desk（远期规划，V2+）** | 局域网/私有对象存储共享只读专题简报包、统一团队偏好策略与合规审计导出包 | **\$15–\$25 / 席位 / 月** `[远期假设]` | 服务 PM 与行业分析团队，不破单机零云库主权 |

### 4.3 单位经济与推理成本模型测算 `[模型测算假设 / 待验证]`

以下按单个典型活跃研究者（每周追踪 20 个频道产生 25 条视频，其中 6 条触发精炼与跨视频追问，其余仅本地过滤）估算厂商侧与用户侧成本：
1. **厂商服务端 COGS（Open Core + 买断桌面端）**：
   - 视频抓取、SQLite 索引、Ollama 初筛、Whisper 转写与关键帧处理 **100% 运行在用户本机** → 厂商端 AI Token/GPU 推理边际成本 **= \$0.00 / 用户 / 月**；
   - 仅承担安装包分发 CDN、签名公证摊销与版本更新带宽（`[假设]` 单活跃用户年带宽与基础设施分摊 **< \$0.50/年**）。
   - 因此 **\$59 买断或 \$39/年授权的软件毛利率可达 ~95%+**（仅扣支付手续费 Stripe/Paddle ~5% 与签名/CDN 分摊），**完全不存在 SaaS “用户越用越亏”的算力倒挂风险**。
2. **用户自带算力感知成本（提升产品极高性价比卖点）**：
   - 80% 常规摘要、翻译与频道过滤走本机 Apple Silicon Ollama（`qwen3.5:9b`）：**\$0 API 费用**；
   - 仅 20% 跨来源深度综合或超长复杂视频按需切换 BYOK（如 DeepSeek / Qwen / BigModel / OpenAI）：按每篇精炼约 15k 输入 + 2k 输出 Tokens 估算，月度重度研究 API 支出通常仅 **\$1–\$4/月**（对比纯云端包装工具动辄 \$15–\$34.8/月，性价比差距近 5–10 倍）。

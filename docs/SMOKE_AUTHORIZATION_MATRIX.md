# Four-Phase Smoke Authorization Matrix

- 设计状态：`NOT AUTHORIZED / NOT EXECUTED`
- 本文件定义未来授权所需的最小输入，不构成任何连接、下载、模型调用、Vault 写入或
  launchd 操作的许可。
- 共通原则：每阶段须有 PO 书面批准、指定操作者/环境、数据最小化、预算/时限、日志和
  成功/停止证据；完成一阶段不隐含批准下一阶段。

| 阶段 | 受控数据与允许范围 | PO 必须明确批准 | 成功证据 | 强制停止条件 |
|---|---|---|---|---|
| 1. 公开 YouTube / 字幕 | 指定公开频道/视频 ID；仅最小元数据与选定字幕路径；无登录、Cookie、`.netrc`、账号或私人内容。 | 视频/频道清单、网络窗口、最大数量/时长、数据保留、操作者和费用为零的预期。 | 每个 ID 的发现/字幕结果、无媒体下载与无凭据读取的安全日志、失败分类和清理记录。 | 任何登录提示、Cookie/账号需求、私有/地区受限内容、非指定 ID、意外媒体下载、日志含字幕全文或超出授权数量。 |
| 2. 受控媒体 + ffmpeg + Whisper | 经确认可用于测试的单一媒体样本；固定 Whisper revision；受控 DATA 目录；不写真实 Vault。 | 媒体再分发/使用权、模型下载或现有模型来源、磁盘/内存上限、ffmpeg 安装/调用、数据保留与清理窗口。 | 模型/revision/权重身份、ffmpeg 版本、输入/输出哈希、资源用量、转写结果的最小质量检查和音频清理结果。 | 许可证/模型来源不清、资源阈值不足、非受控路径、下载额外模型/媒体、网络回退、任何真实 Vault 触碰。 |
| 3. 本机 Ollama + 固定模型 | 仅 loopback `127.0.0.1`/`localhost`/`::1`；固定 `qwen3:8b` digest；合成或已批准的最小文本；无云端。 | Ollama 安装/启动、固定模型拉取/磁盘预算、digest、样本文本、服务端口和停止/清理责任。 | `GET /api/tags` 的固定 digest 匹配、受限 JSON 评分、零云流量、资源/日志审查和服务停止记录。 | 非 loopback URL、digest 不符、自动拉取其他模型、cloud/远程端点、未脱敏文本/日志、服务无法按批准方式停止。 |
| 4. OpenAI + 临时 Vault | 仅合成或经隐私批准的最小化 payload；明确的测试 API 凭据；全新临时 SQLite/DATA/Vault；绝不使用真实 Vault/用户笔记。 | 付费预算、模型、请求上限（每 run 最多 5）、数据分类/保留、凭据注入与销毁、临时 Vault 路径、恢复/清理方案。 | 隔离 SDK 导入白名单和匿名管道证据、`store=False`/无重试、每请求审计、预算、最小化 payload、临时 Vault 原子写/恢复与彻底清理证据。 | 真实 Vault、真实用户内容、密钥出现在 env/argv/文件/日志/异常、预算超限、非批准模型/endpoint、SDK 主进程导入或任何持久化超出临时根。 |

## 阶段前后共同记录

每个执行阶段的负责人须记录：批准文本、日期、候选 commit、依赖/模型版本、数据来源和
分类、命令、起止时间、网络/费用预算、产物位置、日志审查、停止条件是否触发，以及
PO/TL/QA 的结果。失败不应以重试掩盖；应停止并提交范围明确的修复或决策请求。

真实 Vault、用户笔记、生产数据、launchd 注册和发行发布始终不由此矩阵授权。
